
# 🏰 Haunted House 2D

![Godot Engine](https://img.shields.io/badge/Godot-4.x-blue.svg)

**Haunted House 2D** คือเกมแอ็กชันผจญภัยมุมมอง Top-Down 2D ที่สร้างขึ้นด้วย **Godot Engine 4** ผู้เล่นจะต้องเอาชีวิตรอดจากบ้านผีสิง ทำภารกิจไขปริศนา และต่อสู้กับบอสปีศาจ "Hena" เพื่อหาทางเอาชีวิตรอด!

> **เกี่ยวกับโปรเจกต์:** โปรเจกต์นี้ถูกพัฒนาขึ้นเพื่อเป็นส่วนหนึ่งของรายวิชาเรียน โดยมีการประยุกต์ใช้ปัญญาประดิษฐ์ (AI) เข้ามาเป็นผู้ช่วยในการออกแบบระบบและแก้ปัญหาโค้ดตลอดการพัฒนา

---

##  ฟีเจอร์หลักของเกม (Key Features)

* **ระบบภารกิจ (Quest System):** ดำเนินเรื่องราวผ่านภารกิจเป็นขั้นๆ ตั้งแต่การตามหากุญแจ ไปจนถึงการปรุงยาลับ
* **ระบบช่องเก็บของ (Inventory & Hotbar):** สามารถสลับไอเทมใช้งาน เช่น ปืน, ยา หรือไฟฉาย ผ่านปุ่ม Hotbar (1-4)
* **ระบบต่อสู้ (Combat):** เล็งและยิงปืนเพื่อกำจัดซอมบี้ที่เข้ามาขัดขวาง
* **ระบบจุดเซฟอัตโนมัติ (Checkpoint & Auto-Heal):** ไม่ต้องเริ่มใหม่ตั้งแต่ต้น! หากตาย เกมจะส่งคุณกลับไปจุดเริ่มต้นของภารกิจล่าสุดพร้อมฟื้นฟูเลือดและกระสุนจนเต็ม
* **ระบบบอสไฟต์สุดเดือด (Boss Fight):** ฉากเผชิญหน้ากับ Hena Demon ในร่างสมบูรณ์ พร้อมระบบ AI ของบอสและการโจมตีเป็นแพทเทิร์น

---

## วิธีการเล่นและปุ่มควบคุม (Controls)

* **W, A, S, D:** เดิน / เคลื่อนที่
* **คลิกซ้าย (Left Click):** ยิงปืน / ใช้ไอเทม
* **E:** โต้ตอบ (Interact) เช่น เก็บของ, คุยกับ NPC, เปิดประตู
* **R:** รีโหลดกระสุนปืน
* **1, 2, 3, 4:** สลับช่องไอเทมบน Hotbar

---

## เนื้อเรื่องย่อ (Story)

คุณตื่นขึ้นมาในสถานที่ลึกลับโดยไม่รู้ตัว และได้พบกับ **Hena** หญิงสาวปริศนาที่บอกให้คุณช่วยเธอตามหากุญแจและวัตถุดิบเพื่อปรุงยามหัศจรรย์แลกกับการหาทางออก แต่หารู้ไม่ว่ายาขวดนั้นคือ "Revival Potion" ที่จะปลดผนึกร่างปีศาจของเธอ! คุณต้องใช้ไหวพริบและอาวุธที่มี เอาตัวรอดจากผลลัพธ์ที่คุณเป็นคนก่อให้ได้...
